# Exports

Generated by `bun run export` into `dist-data/` (committed) and served by the site at
`/data/connectors.json` and `/data/connectors.csv`. Never edit them by hand: edit `data/` and
regenerate. Per-family documents are also served at `/data/families/<id>.json`.

Both files are deterministic: families sorted by id, no generation timestamp, UTF-8 without BOM,
LF line endings.

## connectors.json

```json
{
  "name": "OpenPlugDB",
  "datasetVersion": "0.1.0",
  "license": "CC0-1.0",
  "schema": "https://openplugdb.org/schemas/connector-family.schema.json",
  "families": [ ... ]
}
```

Each family is its source file without the editor-only `$schema` key, plus one derived field per
variant: `matedBy`, the matings declared from the other side. `matesWith` and `matedBy` together give
the complete, symmetric mating list. `datasetVersion` is the `version` of `package.json`.

## connectors.csv

One header row, then **one row per (variant, electrical profile)**. A variant without any profile
gets one row whose profile columns are empty. Family columns are repeated on each row.

| Convention       | Representation                                                         |
| ---------------- | ---------------------------------------------------------------------- |
| Format           | RFC 4180: comma separator, `"` quoting, `""` escaping, LF line endings |
| Multiple values  | joined with `\|` in one cell, e.g. `50\|60`, `L1\|L2\|L3\|N\|PE`       |
| Unknown (`null`) | the literal `unknown`                                                  |
| Not applicable   | an empty cell                                                          |
| Ranges           | `min..max`, e.g. `200..250`, with `voltage_qualifier` = `range`        |
| Booleans         | `true` / `false`                                                       |
| Standards        | `designation / edition`, edition omitted when unknown                  |
| Matings          | `family/variant`, in both directions                                   |
| Mappings         | values valid for this variant (family-wide or restricted to it)        |
| Formula prefixes | cells starting with `=`, `+`, `-`, `@` are prefixed with `'`           |

Columns:

| Column                                                                                          | Source                                   |
| ----------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `family_id`, `family_name`, `category`, `subcategory`, `status`                                 | family                                   |
| `aliases`, `standards`, `regions`, `countries`                                                  | family, multi-valued                     |
| `variant_id`, `variant_name`, `role`, `contact_gender`                                          | variant                                  |
| `contacts`                                                                                      | contact ids, `unknown` if not documented |
| `mates_with`                                                                                    | derived, both directions                 |
| `profile_id`, `profile_name`, `current_type`, `supply`, `phases`, `neutral`, `protective_earth` | profile                                  |
| `voltage_qualifier`, `voltage_v`, `voltage_reference`                                           | profile voltage                          |
| `current_qualifier`, `current_a`                                                                | profile current                          |
| `frequency_hz`, `max_power_kw`, `cooling`, `jurisdiction`, `confidence`                         | profile                                  |
| `ocpi_2_2_1`, `ocpi_2_3_0`, `openchargemap`, `openstreetmap`                                    | mappings                                 |
| `verification_status`, `last_verified`                                                          | family verification                      |

The CSV is a flat view for spreadsheets. Contact functions, conditions, sources, mechanical notes
and visuals are only in the JSON.
